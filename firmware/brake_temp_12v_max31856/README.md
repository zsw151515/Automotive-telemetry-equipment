# 12V MAX31856 刹车温度固件

## 用途

用于 12V 刹车温度采集节点：

- 12V 供电
- MAX31856
- K 型热电偶
- 可扩展 RaceChrono BLE / RS485 / 本地显示

## 状态

```text
当前状态：待上传固件
```

## 重点风险

- 仅 12V 供电时热源接触热电偶可能导致数据异常或卡住
- 插 USB 后正常时，重点怀疑地参考、输入滤波、电源稳定性和 EMI
- 不要把 MAX31856 fault 隐藏掉
- 不要把异常温度强行显示或发送为 0°C
