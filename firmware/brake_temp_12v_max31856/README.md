# brake_temp_12v_max31856 固件

## 定位

这是一个独立的 12V MAX31856 热电偶采集版本。

它和 `break_temp_alarm_display_12V_RS485` 不是同一个版本，不能混淆。

## 测量目标

```text
卡钳温度
```

## 硬件特征

- 12V 供电
- MAX31856
- K 型热电偶
- 主要负责测量卡钳温度
- 当前还没有接入报警显示
- 当前不等同于 RS485 红外刹车盘测温版本

## 当前状态

```text
当前状态：独立采集 / 测试版本
是否当前报警显示主线：否
是否已接入报警显示：否
```

## 重点风险

- 仅 12V 供电时热源接触热电偶可能导致数据异常或卡住。
- 插 USB 后正常时，重点怀疑地参考、输入滤波、电源稳定性和 EMI。
- MAX31856 fault 不能隐藏。
- 热电偶断线、fault、NaN、异常值必须明确处理。
- 不要把异常温度强行显示或发送为 0°C。

## Codex 修改规则

- 不要把本版本当成 `break_temp_alarm_display_12V_RS485`。
- 不要把卡钳温度写成刹车盘温度。
- 不要加入 RS485 红外测温传感器逻辑，除非用户明确要求。
- 不要擅自接入报警显示架构，除非用户明确要求。
- 修改代码时必须保留 MAX31856 fault 读取和串口日志。
