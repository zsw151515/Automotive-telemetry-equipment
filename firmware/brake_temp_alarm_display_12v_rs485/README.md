# 12V RS485 刹车报警显示中控固件

## 用途

本目录用于车内报警显示中控固件。

主要功能：

- 通过 RS485 读取刹车温度节点
- OLED / TFT 显示当前刹车温度
- 显示 `ALM` 报警阈值
- SET / UP / DOWN 按键设置阈值
- 蜂鸣器超温报警
- 传感器或通信失败时显示 FAIL

## UI 原则

小屏幕版本，例如 1.3 寸 OLED：

- 主温度数字要尽量大
- `ALM` 和 `SET` 逻辑保留
- 不要堆太多状态文字
- FAIL 状态必须明确
- 按键响应必须及时

## Codex 修改规则

- 不要把 RS485 失败显示为 0°C。
- 不要让显示刷新阻塞按键。
- 不要让 RS485 读取阻塞蜂鸣器逻辑。
- 修改后必须说明蜂鸣器逻辑。
- 修改后必须说明是否支持 RaceChrono；通常 RaceChrono BLE 在采集节点侧完成。
