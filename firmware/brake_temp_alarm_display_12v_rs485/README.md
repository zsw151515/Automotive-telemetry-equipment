# break_temp_alarm_display_12V_RS485 固件

## 定位

本目录用于当前主线之一：`break_temp_alarm_display_12V_RS485`。

它和 `brake_temp_12v_max31856` 不是同一个版本，不能混淆。

## 测量目标

```text
刹车盘温度
```

## 传感器类型

```text
RS485 通信方式的红外测温传感器
```

当前上传的传感器手册显示，该类固定式红外测温仪支持 RS485 Modbus RTU 输出，默认地址 0x01，默认 9600 波特率，温度值读取后需要除以 10 得到摄氏度。

## 主要功能

- 通过 RS485 Modbus RTU 读取红外测温传感器
- OLED / TFT 显示当前刹车盘温度
- 显示 `ALM` 报警阈值
- SET / UP / DOWN 按键设置阈值
- 蜂鸣器超温报警
- 传感器或通信失败时显示 FAIL
- 必须支持 RaceChrono Pro BLE 数据发送

## UI 原则

小屏幕版本，例如 1.3 寸 OLED：

- 主温度数字要尽量大
- `ALM` 和 `SET` 逻辑保留
- 不要堆太多状态文字
- FAIL 状态必须明确
- 按键响应必须及时
- RaceChrono / BLE 状态可选，但不要挤占主温度显示

## Codex 修改规则

- 不要把本版本当成 `brake_temp_12v_max31856`。
- 不要把刹车盘温度写成卡钳温度。
- 不要混入 MAX31856 热电偶采集逻辑，除非用户明确要求一体化。
- 不要把 RS485 失败显示为 0°C。
- 不要让显示刷新阻塞按键。
- 不要让 RS485 读取阻塞蜂鸣器逻辑。
- 不要让 RS485 / 显示 / 按键阻塞 RaceChrono BLE。
- 修改后必须说明蜂鸣器逻辑。
- 修改后必须说明 RaceChrono BLE 是否可搜索、可连接、发送哪些通道。
