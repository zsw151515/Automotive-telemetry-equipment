# 中控显示固件

本目录为历史占位。新四路有线胎温中控使用独立目录 `firmware/wired_tire_display`，配合 `firmware/wired_tire_channel`；它不恢复无线胎温高度 v3 的中控发送链路，当前仅为离线研发。

## 用途

本目录用于车内中控显示相关固件。

可能包含：

- ESP32 TFT 胎温高度中控
- ESP-NOW 接收胎温高度节点
- 触控 ACK 控制
- 多页显示
- 刹车温度显示扩展

## 注意事项

- 车内显示优先清楚可读。
- 不要让显示刷新阻塞通信。
- 小屏幕不要堆太多信息。
- 控制节点命令必须有 ACK 或明确反馈。
