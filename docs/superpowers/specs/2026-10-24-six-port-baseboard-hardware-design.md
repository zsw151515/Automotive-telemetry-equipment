# 六接口底板工程样机设计

用户已授权按“器件选型／引脚表 → 原理图 → PCB布局 → 审查 → 少量样板”推进，交付嘉立创EDA专业版工程。延续已确认的7B套件、同壳安装、四胎温完整热图、两前刹车、后台蜂鸣和原RaceChrono数据定义。7B和探头未到货，首版用于工程验证，不把图纸或软件检查称作实物核准。

工作方案为四个ESP32-C3-MINI-1-H4X胎温单元和一个ESP32-S3-WROOM-1-N8双刹车单元，装在同一块PCB；选择H4X以使用原厂现行型号和库中真实封装。S3代替第五C3，使用UART1/2；现有离线固件仍是C3工程，后续必须独立移植，不能直接标为S3可用。

7B保留原显示、背光32、复位33、触摸7/8/23和C6连接。板间SPI仍是五个独立从机，SN74HCS151将五个DMA READY电平用三地址线加一输入读取，将P4预算从13降为12个信号。选择器不改变帧格式、token或CRC；切换稳定时间和读取适配需在后续固件、台架中验证。每桥用四路3.3V单向三态缓冲隔离SCK/MOSI/CS及MISO，MISO使能取主机侧CS，防止启动毛刺直接扰动共享总线；MCU侧输入保留限流串阻。

各RS485口独立THVD2410DR、默认关闭的DE、独立电源支路保护。DE_CMD与TX_ARM通过硬件AND，ARM有外部下拉；原生USB维护，GPIO20不再同时作为C3 UART0下载输入。两刹车保持各自UART/收发器。六个外部接口暂定统一电源/GND/A/B定义和锁扣连接器，厂家封装、插拔空间及实际线束定义核对后才能冻结后盖开孔。

输入按12V点火设计，主保护采用LM74900-Q1、共漏极背靠背MOS和保险/TVS；两路降压分别供5V屏幕及3.3V逻辑，按3A能力开展预算和热设计，能力上限不等于实测连续负载。探头支路独立TPS1H200A-Q1限流保护。UVLO/OVP、冷启动关机、反灌和六支路故障需明确记录；不宣称浪涌认证。屏幕5V需防USB反灌，烧录接口不直接向逻辑供电母线注入USB5V。

PCB以150×75mm占位开展四层布局，实际轮廓可随射频净空、连接器和电源布局调整；对应外壳后盖参数同步。模块天线所有铜层禁布，并核对屏幕金属背板间距。主保护、两降压的高电流环路、Kelvin采样和热焊盘按各原厂指南布局；LM74900的RTN裸焊盘浮置，不能误接地，LMR33630的AGND裸焊盘必须接地。

目前自动化使用用户已导入的官方API Gateway和本机3.2.149。新工程名称“六接口中控底板 V0.1 工程样机”。实际API先对照本机版本；图纸导出、网表、ERC/DRC、元件/焊盘读回分别留证。原理图完成前不输出可下单Gerber；布局未布线时明确标注预布局。硬件未核准时不启用固件Approved profile。
