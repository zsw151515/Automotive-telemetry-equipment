# 六接口中控板间与刹车接口

状态：离线实现，未实物验证。

四胎温依然为原 Snapshot v1 固定1728字节、FL/FR/RL/RR，独立CS/READY；BLE RejsaRubberTrac 0x1FF7、三特征每包20字节，B4–B19为8个小端int16温度计数/10，不属于DIY CAN。刹车是独立第五C3、独立256字节BrakeLink，不能编成WheelId=5。

## BrakeLink v1


请求与响应各固定256字节、全双工流水；首个旧token响应丢弃，与原1728字节胎温从机各有独立CS。全部多字节字段小端，248–251为前248字节IEEE CRC32，252–255零填充，未定义字节必须零。

配置先保存确认后生效；存储结果未知时保留原有效配置并阻止新变更，读回可能确认完整旧值或新值，不宣称回滚。重复命令不写Flash、不延长静音；缓存8条外加会话ID高水位。

## 刹车 RaceChrono DIY CAN

设备名 `N BrakeTemp`，Service `0x1FF8`，通知/读特征 `0x0001`，过滤写特征 `0x0002`。每条通知B0–B3为uint32小端CAN ID；以下payload从B4开始，温度/16位量均大端。手机计算的byte索引从CAN payload起算；具体RaceChrono输入语法待手机实测，不能把通知的4字节ID当payload。

|CAN ID/PID|含义|payload|单位/缩放|计算定义|
|---|---|---|---|---|
|0x100|前左实测盘温|B0–B1 signed int16 BE|℃，×0.1|signed16(B0×256+B1)/10|
|0x101|前右实测盘温|同上|同上|同上|
|0x102|有效盘温最大值|同上|同上|同上|
|0x103|Fast表面滤波估算|同上|同上|同上|
|0x104|Core热浸估算|同上|同上|同上|
|0x105|Dose热负荷|B0–B1 uint16 BE|模型量，×0.1|(B0×256+B1)/10|
|0x106|状态|B0 uint8|0 OK/1 WARN/2 ALARM/3 FAIL|B0|
|0x107|ALM阈值|B0–B1 uint16 BE|℃，×1|B0×256+B1|

温度0x7FFF为无效，不能作为3276.7℃记录；负数须做16位符号扩展。一般通知总长6字节，状态5字节。过滤00严格1字节拒绝全部，01至少3字节允许全部（B1–2大端间隔ms），02至少7字节新增PID（B1–2间隔/B3–6 PID，兼容大小端）；12槽去重、满时原子拒绝。最短/零间隔150ms，请求更慢间隔受尊重。非法命令不改变过滤状态。
