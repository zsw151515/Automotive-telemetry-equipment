# 02 硬件版本说明

## 1. 胎温高度节点 v2

胎温高度节点 v2 是较早的验证版本，主要用于验证：

- MLX90640 胎温读取
- VL53L1X 高度读取
- RaceChrono BLE 输出
- ESP-NOW 到中控显示
- 电池电压检测
- 基础按键 / LED 状态

### 1.1 主要硬件

- MCU：ESP32-C3 模块 / 开发板形态
- 胎温传感器：MLX90640
- 高度传感器：VL53L1X
- 供电：锂电池 + 3.3V LDO
- 通信：BLE + ESP-NOW
- USB：Type-C

### 1.2 典型引脚

```cpp
const int SDA_PIN = 8;
const int SCL_PIN = 10;
const int VBAT_ADC_PIN = 1;
const int LED_STAT_PIN = 2;
const int BTN_PIN = 3;
```

### 1.3 作用

v2 代码可作为胎温高度功能的稳定参考版本。后续重构 v3 时，不应丢失 v2 已验证稳定的通信和传感器处理逻辑。

---

## 2. 胎温高度节点 v3

v3 是当前更接近产品化的版本，重点加入单按键电源控制、Type-C 优化、更多测试点和更明确的电源路径。

### 2.1 主要硬件

- MCU：ESP32-C3
- 胎温传感器：MLX90640
- 高度传感器：VL53L1X
- 电源控制：LTC2954
- 电池充电：TP4057
- 3.3V LDO：ME6211C33M5G-N
- USB ESD：USBLC6-2SC6
- P-MOS：AO3407A
- Type-C 接口

### 2.2 v3 关键修复结论

当前已经通过实测确认：

- 应使用 `LTC2954CTS8-2#TRPBF`
- `R_BTN_PULL` 应 DNP / 删除
- `PWR_KILL -> SYS_3V3` 增加 47kΩ 上拉
- 该方案在电池供电下连续约 30 次开机测试稳定

### 2.3 典型引脚

```cpp
const int SDA_PIN          = 8;
const int SCL_PIN          = 10;
const int VBAT_ADC_PIN     = 1;
const int LED_STAT_PIN     = 2;  // 低电平点亮
const int BTN_PIN          = 3;  // 低电平有效
const int PWR_KILL_PIN     = 4;  // HIGH 保持电源
const int PWR_INT_PIN      = 5;
const int VL53_XSHUT_PIN   = 6;
const int VL53_INT_PIN     = 7;
```

### 2.4 v3 修改注意事项

不要轻易修改：

- `PWR_KILL_PIN`
- `PWR_INT_PIN`
- `BTN_PIN`
- `VL53_XSHUT_PIN`
- `VL53_INT_PIN`
- RaceChrono BLE 相关逻辑

v3 的电源控制是历史上出过严重问题的部分，所有相关修改必须保守。

## 3. 12V MAX31856 刹车温度节点

该版本用于刹车温度监测，目标是汽车 12V 供电和真实赛道环境使用。

### 3.1 主要硬件

- MCU：ESP32 / ESP32-C3，视具体板子而定
- 温度芯片：MAX31856
- 传感器：K 型热电偶
- 供电：汽车 12V -> 降压 -> 3.3V
- 输出：OLED / TFT / BLE / RS485，视版本而定
- 报警：蜂鸣器 + 屏幕阈值显示

### 3.2 重点风险

- 热电偶线较长，容易引入干扰
- 刹车附近高温和震动强
- 车载 12V 电源有浪涌和噪声
- MAX31856 前端需要合理滤波和接地
- 仅 12V 供电时出现过热源接触导致数据卡住 / 归 0 的问题

### 3.3 软件处理原则

- 保留 MAX31856 fault 读取和日志
- 不要把 fault 简单隐藏
- 异常值要滤波，但不能误导用户
- 报警逻辑必须明确
- 显示界面优先大字体和清楚报警

---

## 4. 中控显示

中控显示有多个方向：

- ESP32 + TFT 触控屏
- ESP32 + OLED 小屏
- RS485 接收刹车温度
- ESP-NOW 接收胎温高度节点

### 4.1 显示原则

- 车内快速可读
- 字体要大
- 信息不要堆太满
- 报警温度和当前温度要清楚
- 按键响应要及时
- 蜂鸣器逻辑要可预测

### 4.2 不建议

- 不建议在小 OLED 上显示过多状态文字
- 不建议牺牲主温度数字大小
- 不建议把报警和连接状态混在一起导致现场误判
