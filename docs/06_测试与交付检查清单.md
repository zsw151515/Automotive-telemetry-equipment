# 06 测试与交付检查清单

本文件用于产品交付前检查。目标是减少客户拿到设备后出现开机失败、连接失败、数据异常、报警异常等问题。

## 1. 通用外观检查

- [ ] PCB 无明显刮伤、断线、焊盘脱落
- [ ] Type-C 母座无歪斜、虚焊、少锡
- [ ] 电池座 / 连接器焊接牢固
- [ ] 传感器连接器方向正确
- [ ] 按键手感正常
- [ ] LED 方向正确
- [ ] 螺丝孔无堵塞
- [ ] 外壳安装后没有压到元件
- [ ] 线束有应力释放

## 2. 上电前电气检查

- [ ] BAT_RAW 对 GND 无短路
- [ ] SYS_3V3 对 GND 无短路
- [ ] USB_5V 对 GND 无短路
- [ ] SDA / SCL 对 GND 无短路
- [ ] BOOT / EN 电平网络无短路
- [ ] Type-C CC1 / CC2 到 GND 约 5.1kΩ
- [ ] USB D+ / D- 没有互短

## 3. 胎温高度节点 v3 电源检查

- [ ] 使用 `LTC2954CTS8-2#TRPBF`
- [ ] `R_BTN_PULL` 已 DNP / 删除
- [ ] `PWR_KILL -> SYS_3V3` 已加 47kΩ 上拉
- [ ] 未按按钮时 BTN_NODE 状态正常
- [ ] 按下按钮时 BTN_NODE 能拉到 0V
- [ ] 电池供电可稳定开机
- [ ] 连续开机 20 次以上无失败
- [ ] 长按关机功能正常
- [ ] 关机后电流符合预期

## 4. USB 检查

- [ ] 插入电脑后可识别串口
- [ ] Arduino IDE 可正常烧录
- [ ] 不按 BOOT 可正常进入运行
- [ ] 必要时按 BOOT 可进入下载
- [ ] D+ / D- 串阻阻值正确
- [ ] Type-C 插头轻微晃动不掉线
- [ ] 若 Windows 提示无法识别 USB，优先复查 Type-C 母座焊接

## 5. 传感器检查

### 5.1 I2C 扫描

- [ ] MLX90640 地址 `0x33` 可扫描到
- [ ] VL53L1X 地址 `0x29` 可扫描到
- [ ] SDA / SCL 静态电压约 3.3V
- [ ] I2C 串联电阻不是 10kΩ 级别

### 5.2 MLX90640

- [ ] 初始化成功
- [ ] 热源靠近时温度上升
- [ ] 无明显 -20°C / 90°C 异常跳变
- [ ] 左中右区域数据变化合理
- [ ] 连续运行 10 分钟无掉线

### 5.3 VL53L1X

- [ ] 初始化成功
- [ ] 对准目标时距离合理
- [ ] 远距离 / 无目标时不会导致程序卡死
- [ ] 校准高度功能正常

## 6. RaceChrono BLE 检查

- [ ] 串口显示 BLE advertising started
- [ ] iPhone RaceChrono Pro 可以搜索到设备
- [ ] 设备名与轮位匹配
- [ ] 可连接
- [ ] 连接后有温度数据
- [ ] 热源移动时数据有响应
- [ ] 连续连接 10 分钟以上不掉线
- [ ] 断开后可重新连接
- [ ] 多个节点同时存在时轮位不混乱

## 7. ESP-NOW / 中控检查

- [ ] 节点能发送数据到中控
- [ ] 中控能显示对应轮位
- [ ] 数据刷新不卡顿
- [ ] ACK 控制正常
- [ ] 中控发送镜像 / 校准命令后节点有响应
- [ ] 中控显示不会影响 BLE 连接

## 8. 12V 刹车温度节点检查

- [ ] 12V 输入无短路
- [ ] 3.3V 稳定
- [ ] MAX31856 初始化成功
- [ ] 冷端温度合理
- [ ] 热电偶加热时温度上升
- [ ] 断开热电偶时能显示故障
- [ ] fault 状态能打印
- [ ] 蜂鸣器报警逻辑正确
- [ ] 报警阈值设置能保存或生效
- [ ] 仅 12V 供电时热源测试不应卡死
- [ ] 插 USB 和不插 USB 行为一致

## 9. 显示检查

- [ ] 主温度数字足够大
- [ ] 报警阈值 ALM 清楚
- [ ] SET / UP / DOWN 按键响应及时
- [ ] 报警状态明显
- [ ] 蜂鸣器开关状态明确
- [ ] 无传感器时显示 FAIL 或明确故障，不误显示正常温度
- [ ] 夜间 / 白天都能看清

## 10. 抗震和安装检查

- [ ] 传感器支架牢固
- [ ] 螺丝有防松措施
- [ ] 线束不会拉扯焊点
- [ ] 热电偶线有固定点
- [ ] 轮拱附近不会磨线
- [ ] 设备盒不会因震动脱落
- [ ] 高温区域与塑料 / 电池有足够距离

## 11. 交付前老化测试

建议至少做：

- [ ] 连续运行 30 分钟
- [ ] 多次开关机
- [ ] 多次插拔 USB
- [ ] RaceChrono 多次连接 / 断开
- [ ] 热源快速变化测试
- [ ] 震动模拟测试
- [ ] 电池低电压测试
