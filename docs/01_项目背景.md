# 01 项目背景

## 1. 项目定位

本项目是一个面向赛道驾驶的汽车遥测系统，核心目标是在真实赛道环境中实时采集和记录车辆关键温度与姿态数据。

主要关注：

- 轮胎胎面温度分布
- 悬挂高度 / 离地距离变化
- 刹车温度
- 车内实时显示
- RaceChrono Pro 数据记录
- 后期视频叠加 / 数据分析

项目不是单纯实验板，而是逐步向可销售、可交付、可维护产品演进。

## 2. 使用场景

典型使用场景：

1. 赛道日 / 练习日
2. 车辆调校测试
3. 胎压和胎温分析
4. 刹车系统温度监控
5. 悬挂行程 / 车身姿态分析
6. RaceChrono Pro 记录圈速和遥测数据

设备需要承受：

- 长时间震动
- 高温环境
- 车内 / 轮拱附近电磁干扰
- 电池供电波动
- 反复上电 / 断电
- 用户现场快速操作

## 3. 当前系统组成

### 3.1 胎温高度节点

功能：

- 采集 MLX90640 红外温度阵列
- 提取轮胎内 / 中 / 外温度区域
- 采集 VL53L1X 距离数据
- 通过 BLE 发给 RaceChrono
- 通过 ESP-NOW 发给中控

### 3.2 刹车温度节点

功能：

- MAX31856 读取 K 型热电偶
- 测量刹车盘 / 卡钳附近温度
- 本地报警或发送到中控
- 可扩展到 RaceChrono

### 3.3 中控显示

功能：

- 车内显示温度和报警信息
- 接收节点数据
- 提供报警阈值设置
- 可能通过触控或按键控制节点行为

### 3.4 RaceChrono Pro

用途：

- 记录圈速
- 记录胎温 / 刹车温度 / 其他通道
- 赛后分析
- 视频叠加

## 4. 项目设计哲学

本项目必须优先做到：

1. 能在真实赛道用
2. 不容易掉线
3. 数据不要乱跳
4. 用户容易判断设备状态
5. 现场能快速排查
6. 代码和硬件都能长期维护

不建议为了追求“功能多”引入过度复杂的架构。

## 5. Codex 使用目的

Codex 在本项目中的主要作用：

- 帮助维护固件代码
- 根据硬件版本生成完整 `.ino`
- 审查潜在 bug
- 整理文档
- 生成测试清单
- 协助建立稳定的工程结构

Codex 不应该在不了解硬件背景时大改代码。修改前必须阅读 `CODEX.md` 和相关文档。
