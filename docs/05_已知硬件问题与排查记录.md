# 05 已知硬件问题与排查记录

本文件记录项目中已经遇到过、验证过、或高度怀疑的硬件问题。后续 Codex / ChatGPT 修改代码或审查硬件时，应优先参考这里，避免重复踩坑。

## 1. v3 电源控制严重问题与最终修复方向

### 1.1 问题现象

早期 v3 板使用 `LTC2954CTS8-1#TRPBF` 时，出现过：

- 电池供电下偶发开机失败
- 长按关机后状态不稳定
- 某些状态下 SYS_VBAT / SYS_3V3 异常保持
- 按键和 KILL 逻辑不符合最终产品预期

### 1.2 实测修复结论

后续实测确认：

- 更换为 `LTC2954CTS8-2#TRPBF`
- 删除 / DNP `R_BTN_PULL`
- 在 `PWR_KILL -> SYS_3V3` 增加 47kΩ 上拉

该方案在电池供电条件下连续约 30 次开机测试稳定，未再出现偶发开机失败。

### 1.3 后续要求

后续 v3 / v3.1 硬件应固定：

```text
U_PWR = LTC2954CTS8-2#TRPBF
R_BTN_PULL = DNP / 删除
PWR_KILL -> SYS_3V3 = 47kΩ 上拉
```

不要再回到 `LTC2954-1` 方案。

## 2. Type-C 母座动态接触问题

### 2.1 问题现象

某块 v3 新贴片板在 Windows 上提示：

```text
无法识别 USB 设备
```

### 2.2 当时已检查项目

- 供电正常
- D+ / D- 静态导通正常
- 22Ω 串阻正常
- CC 电阻正常
- BOOT / EN / IO8 电平正常
- 更换 MCU 无效
- 拆 USBLC6 无效

### 2.3 最终解决

重新贴焊 Type-C 母座后问题解决。

### 2.4 结论

Type-C 母座即使万用表静态导通正常，也可能存在：

- 焊点虚焊
- 弹片接触不良
- 插头插入后动态接触不良
- D+ / D- 差分线实际接触不稳定

后续遇到 Windows 无法识别 USB，但静态测量都正常时，应优先怀疑 Type-C 母座焊接 / 接触质量。

## 3. I2C 串联电阻误焊为 10kΩ

### 3.1 问题现象

I2C 扫描不到 MLX90640 / VL53L1X。

### 3.2 排查现象

测得部分 I2C 串联电阻两端约 10kΩ。

### 3.3 结论

I2C 串联电阻不应是 10kΩ。

典型：

```text
I2C 上拉：4.7kΩ / 10kΩ
I2C 串联：0Ω / 22Ω / 47Ω
```

10kΩ 放在串联位置会严重影响通信。

## 4. MLX90640 / VL53L1X 初始化失败

### 4.1 常见原因

- SDA / SCL 焊接不良
- 串联电阻阻值错误
- 模块供电不稳定
- MLX90640 模块 5V / 3.3V 供电类型搞错
- VL53L1X 上电时 XSHUT 状态不正确
- VL53L1X 启动时目标距离异常

### 4.2 排查建议

1. 串口运行 I2C scan。
2. 确认是否出现：
   - `0x33`：MLX90640
   - `0x29`：VL53L1X
3. 测量传感器 VCC。
4. 测量 SDA / SCL 静态电压是否被拉到 3.3V。
5. 检查 I2C 串联电阻阻值。
6. 重新焊接传感器连接器。

## 5. VL53L1X 启动位置影响

VL53L1X 曾出现：

- 对着天空 / 远距离启动时读数异常
- 启动后显示 -1 或 0
- 对准合适目标重启后恢复

建议：

- 初始化时增加失败重试
- 启动时尽量让传感器面向有效目标
- 不要把一次初始化失败直接判定为硬件损坏

## 6. 12V MAX31856 刹车节点：热源接触导致数据异常

### 6.1 问题现象

在 12V MAX31856 刹车节点中出现：

- 只用 12V 供电、USB 不供电时
- 热电偶接触打火机或高温热源
- RaceChrono 温度数据会卡住或归 0
- 插上 USB 后一切正常

### 6.2 重点怀疑方向

- 12V 转 3.3V 电源瞬态响应不足
- 地参考变化
- 热电偶输入共模干扰
- MAX31856 前端滤波不足
- 热电偶接触火焰 / 金属热源时引入噪声
- USB 插入后通过电脑地改善了参考地

### 6.3 软件上不能简单掩盖

代码应保留：

- MAX31856 fault 读取
- fault 串口打印
- NaN / 异常值判断
- 连续失败计数
- 断线 / 故障显示

不要简单把异常温度强行改成 0 或继续发送旧值而不提示。

## 7. 电子灌封胶注意事项

节点板测试稳定后可以考虑局部灌封，但要注意：

- MLX90640 / VL53L1X 正面光学窗口不能被普通胶覆盖
- Type-C、按钮、连接器不应完全灌死，除非最终设计确认
- 电池不建议整体灌封
- 发热器件周围要考虑散热
- 先做一块样机验证，不要直接批量灌封

---

## 8. 抗震固定经验

赛道环境下，传感器和支架固定应优先考虑：

- 螺丝 + 防松结构
- 双螺母 / 金属锁紧螺母 / Nord-Lock 防松垫片
- 合适强度等级螺母
- 避免只依赖胶水
- 线束必须有应力释放

传感器固定失败会直接导致数据失真或设备脱落，优先级很高。
