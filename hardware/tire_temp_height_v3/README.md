# 胎温高度节点 v3 硬件（当前主线）

## 定位

胎温高度节点 v3 是当前项目的主要硬件版本之一，目标是从测试板走向可交付、可发售的稳定版本。

## 主要功能

- MLX90640 胎温监测
- VL53L1X 悬挂高度 / 离地距离监测
- ESP32-C3 主控
- RaceChrono Pro BLE 数据记录
- 可扩展 ESP-NOW 到中控显示
- 单按键电源控制
- Type-C 烧录 / 充电
- 锂电池供电

## 关键硬件结论

后续 v3 / v3.1 应固定：

```text
U_PWR = LTC2954CTS8-2#TRPBF
R_BTN_PULL = DNP / 删除
PWR_KILL -> SYS_3V3 = 47kΩ 上拉
```

该组合已经通过电池供电约 30 次连续开机测试，未再出现偶发开机失败。

## 注意事项

- 不要再使用不适合当前电源逻辑的 LTC2954-1 方案。
- Type-C 母座即使万用表导通正常，也可能存在动态接触问题。
- 传感器 I2C 串联电阻不要误焊成 10kΩ。
- 硬件和固件修改必须优先保证 RaceChrono BLE 稳定。
