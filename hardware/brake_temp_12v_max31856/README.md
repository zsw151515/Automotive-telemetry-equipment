# brake_temp_12v_max31856 硬件（独立热电偶卡钳测温版本）

## 定位

本目录用于 `brake_temp_12v_max31856` 硬件资料。

这是一个独立的 12V MAX31856 + K 型热电偶采集版本，主要负责测量卡钳温度。

它和 `brake_temp_12v_rs485`、`brake_temp_alarm_display_12v_rs485` 不是同一个版本，不能混淆。

## 版本边界

```text
brake_temp_12v_max31856
= MAX31856 + K 型热电偶
= 测卡钳温度
= 当前未接入报警显示
= 独立采集 / 测试版本

brake_temp_12v_rs485
= RS485 红外测温传感器
= 测刹车盘温度
= 不带显示报警
= 初代版本，非当前重点

brake_temp_alarm_display_12v_rs485
= RS485 红外测温传感器
= 测刹车盘温度
= 带显示、ALM、按键、蜂鸣器、RaceChrono
= 当前刹车节点板重点推进版本
```

## 测量目标

```text
卡钳温度
```

不要把该版本的数据命名成刹车盘温度。

## 主要硬件

- ESP32 / ESP32-C3，视具体板子而定
- MAX31856 热电偶数字转换器
- K 型热电偶
- 12V 输入电源
- 12V -> 3.3V 降压电源
- 可选状态 LED / 调试接口

## 关键设计风险

- K 型热电偶线较长，容易引入干扰。
- 卡钳附近高温和震动强。
- 车载 12V 电源存在噪声、浪涌和地电位变化。
- MAX31856 前端需要合理滤波和接地。
- 仅 12V 供电、不插 USB 时，热源接触热电偶曾出现数据异常 / 卡住风险。
- 插 USB 后恢复正常时，应重点怀疑地参考、输入滤波、电源稳定性和 EMI。

## MAX31856 设计注意事项

- 保留热电偶输入滤波位置。
- 保留 MAX31856 电源去耦。
- SPI 走线尽量短且清晰。
- 热电偶接口要有可靠机械固定。
- 热电偶线束需要应力释放。
- 不要把 MAX31856 fault 从软件中隐藏。

## 不包含内容

当前版本不包含：

- RS485 红外测温传感器
- OLED / TFT 报警显示
- ALM 报警阈值设置
- SET / UP / DOWN 按键显示交互
- 当前主线蜂鸣器报警显示逻辑

除非用户明确要求，不要把这些功能混入本版本。
