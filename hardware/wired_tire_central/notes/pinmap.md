# 新中控引脚审查记录

状态：没有实物板和核准引脚，当前不能用于接线或制造。

2026-10-24 最新设计为 7B 套件＋六接口底板，四胎温单元加第五刹车单元。P4 引脚核查以实际 7B PH2.0 接口、BSP 和原理图为准；原四轮 SPI 为 11 GPIO，六口设计工程基线扩展为 3 总线＋5 CS＋5 READY＝13 GPIO。第五 C3 采用双 UART 独立 RS485＋SPI/READY＋蜂鸣需约 12 GPIO，原生 USB 另占18/19，Flash/启动脚/UART0开机输出必须审查。此为预算而非核准分配，所有真实引脚仍未定，适配时追加 -1 到核准引脚的对照。

需要核准的信号：每个 C3 的 UART RX/TX、RS485 DE/RE、SPI2 SCK/MOSI/MISO/CS/握手、启动电平、USB/烧录接口；P4 的四个片选/握手、SPI 和屏幕/背光/复位/DSI 电源。

离线配置使用 -1 表示未分配，并禁用真实 I/O。它是编译保护值，不是有效 GPIO。硬件 profile 缺失时显式硬件构建必须失败。

取得实际板型、引脚资料和屏幕后，记录每个信号的引脚号、启动约束、与其他外设冲突检查和审查版本。后续修改必须追加新旧对照。
