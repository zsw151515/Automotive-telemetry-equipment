# SPI 验证记录

状态：仅离线核心测试通过，未进行 C3/P4 真实接线或测量。

已验证：固定快照的字节布局、CRC、轮位/token、重启/序号回绕元数据、在途 DMA 缓冲租约、源数据年龄与请求/主机经过时间叠加及溢出保护。

传输采用等长 1728 字节事务，首事务可收到无效或旧 token 的排队响应，必须丢弃；随后匹配 token 才发布。本方案增加传输量，至少需要两次事务取得新请求对应快照；四路 4 Hz 的基线传输量约 55 kB/s（单方向计），需要实测吞吐与 100 ms 窗口。

实物需要检查：1 MHz mode 0 的建立/保持时间，DMA 对齐和内存能力，就绪信号时序，四路 MISO 三态、复位/断线/片选故障、P4 重启和从机停止响应，以及 BLE 与显示是否持续。未完成前不冻结 PCB。
