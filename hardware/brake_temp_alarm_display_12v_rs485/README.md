# brake_temp_alarm_display_12V_RS485 硬件（当前重点版本）

## 定位

本目录用于当前刹车节点板重点推进版本：`brake_temp_alarm_display_12V_RS485`。

该版本是 `brake_temp_12v_rs485` 初代版本的升级方向，增加了显示、报警、按键、蜂鸣器和 RaceChrono 数据发送。

## 版本边界

```text
brake_temp_12v_max31856
= MAX31856 + K 型热电偶
= 测卡钳温度
= 当前未接入报警显示

brake_temp_12v_rs485
= RS485 红外测温传感器
= 测刹车盘温度
= 不带显示报警
= 初代版本，非当前重点

brake_temp_alarm_display_12v_rs485
= RS485 红外测温传感器
= 测刹车盘温度
= 带显示、ALM、按键、蜂鸣器、RaceChrono
= 当前刹车节点板重点推进版本
```

## 系统目标

该版本用于真实赛道环境下监测刹车盘温度，包含：

1. RS485 红外测温传感器
2. OLED / TFT 报警显示
3. `ALM` 报警阈值设置
4. SET / UP / DOWN 按键
5. 蜂鸣器超温报警
6. RaceChrono Pro BLE 数据记录

## 关键设计要求

- RS485 线束必须考虑抗震、防松、GND 参考和 A/B 极性。
- 显示屏需要足够大字体，车内一眼可读。
- 按键必须响应及时。
- 蜂鸣器报警逻辑必须清楚。
- RaceChrono BLE 不能被 RS485 读取、显示刷新或按键扫描阻塞。
- RS485 读取失败不能显示或发送为正常 0°C。
- 不要把 MAX31856 热电偶卡钳测温硬件混入本版本。

## RS485 红外测温传感器要点

- 固定式红外测温仪
- 非接触测温
- 测量目标：刹车盘表面温度
- RS485 Modbus RTU 输出
- 默认地址：0x01
- 默认波特率：9600
- 默认格式：8N1
- 读取功能码：0x03
- 温度寄存器：0x0000
- 返回温度值需要除以 10
