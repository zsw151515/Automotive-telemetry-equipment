# break_temp_alarm_display_12V_RS485 / RS485 红外刹车盘测温硬件（当前主线）

## 定位

本目录用于 `break_temp_alarm_display_12V_RS485` 相关硬件资料。

这是当前项目主线之一，与胎温高度 v3 并列重点维护。

## 系统目标

该系统用于真实赛道环境下监测刹车盘温度，包含：

1. RS485 红外测温传感器
2. 车内 OLED / TFT 报警显示中控
3. SET / UP / DOWN 按键
4. 蜂鸣器超温报警
5. RaceChrono Pro BLE 数据记录

## 重要边界

```text
brake_temp_12v_max31856 = MAX31856 + K 型热电偶，测卡钳，目前未接入报警显示
break_temp_alarm_display_12V_RS485 = RS485 红外测温传感器，测刹车盘，负责显示 / 报警 / RaceChrono
```

不要把 MAX31856 热电偶卡钳测温硬件混入本目录。

## RS485 红外测温传感器要点

当前传感器手册要点：

- 固定式红外测温仪
- 非接触测温
- 测量目标：刹车盘表面温度
- RS485 Modbus RTU 输出
- RS485 型号供电：5~36V DC
- 默认地址：0x01
- 默认波特率：9600
- 默认格式：8N1
- 读取功能码：0x03
- 温度寄存器：0x0000
- 返回温度值需要除以 10
- 红色：5~36V DC+
- 黑色：0V
- 绿色：RS485 A+ (T/R+)
- 黄色：RS485 B- (T/R-)
- 银色：屏蔽线

## 关键设计要求

- RS485 线束必须考虑抗震、防松、GND 参考和 A/B 极性。
- 传感器光路必须对准刹车盘，不能被导风板、支架、线束遮挡。
- 红外测温传感器镜头必须避免灰尘、油污、刹车粉尘长期覆盖。
- 显示中控小屏幕优先大字体，不要堆太多状态文字。
- 该版本必须支持 RaceChrono Pro 数据记录。
- 不要把异常读数显示或发送为正常 0°C。
- 不要把数据命名为卡钳温度，应明确为刹车盘温度。
