# break_temp_alarm_display_12V_RS485 / 12V RS485 刹车温度硬件（当前主线）

## 定位

本目录用于 12V RS485 刹车温度系统硬件资料。

这是当前项目主线之一，与胎温高度 v3 并列重点维护。

## 系统目标

该系统用于真实赛道环境下监测刹车温度，包含：

1. 12V MAX31856 刹车温度采集节点
2. RS485 通信
3. 车内 OLED / TFT 报警显示中控
4. 蜂鸣器超温报警
5. RaceChrono Pro BLE 数据记录

## 关键设计要求

- 12V 输入必须考虑车载电源噪声和瞬态。
- MAX31856 前端必须考虑热电偶输入滤波和抗干扰。
- RS485 线束必须考虑抗震、防松、GND 参考和 A/B 极性。
- 显示中控小屏幕优先大字体，不要堆太多状态文字。
- 该版本也必须支持 RaceChrono Pro 数据记录。
- 不要把异常读数显示或发送为正常 0°C。

## 已知重点问题

- 仅 12V 供电、不插 USB 时，热电偶接触热源曾出现 RaceChrono 数据卡住 / 归 0 的问题。
- 插 USB 后正常时，重点怀疑地参考、热电偶输入滤波、3.3V 稳定性、EMI 和 MAX31856 前端抗干扰。
- 代码不能只从软件上掩盖 fault，硬件也必须继续优化。
