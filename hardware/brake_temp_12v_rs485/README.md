# brake_temp_12v_rs485 硬件（初代 RS485 版本，非当前重点）

## 定位

本目录用于 `brake_temp_12v_rs485` 初代硬件资料。

这是 RS485 红外刹车盘测温的早期版本，**不带显示报警**，不是当前重点推进对象。

当前重点推进版本是：

```text
brake_temp_alarm_display_12v_rs485
```

## 系统目标

该版本用于验证：

- RS485 红外测温传感器
- 刹车盘温度读取
- 基础 12V / 5V 供电
- 基础 RS485 接线和通讯

该版本不包含：

- OLED / TFT 显示
- ALM 报警阈值设置
- SET / UP / DOWN 按键
- 蜂鸣器报警
- 当前主线的报警显示交互

## RS485 红外测温传感器要点

当前传感器手册要点：

- 固定式红外测温仪
- 非接触测温
- 测量目标：刹车盘表面温度
- RS485 Modbus RTU 输出
- RS485 型号供电：5~36V DC
- 默认地址：0x01
- 默认波特率：9600
- 默认格式：8N1
- 读取功能码：0x03
- 温度寄存器：0x0000
- 返回温度值需要除以 10
- 红色：5~36V DC+
- 黑色：0V
- 绿色：RS485 A+ (T/R+)
- 黄色：RS485 B- (T/R-)
- 银色：屏蔽线
